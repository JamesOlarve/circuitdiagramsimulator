Purpose

Circuit Builder & Simulator is a browser-based tool for drawing clean electrical and electronics circuit diagrams and simulating supported DC circuits. Users can place standard circuit components on a grid canvas, connect terminals with wires, edit labels and values, inspect simulated measurements, and export the finished schematic for reports, lessons, worksheets, presentations, and laboratory documentation.

The tool is intended for fast schematic communication and basic linear DC circuit analysis. It helps users create readable circuit layouts and solve resistor-based DC circuits without installing dedicated CAD or electronics design software.

Primary Use Cases

  • Create circuit diagrams for physics and electronics lessons.
  • Solve linear resistor-based DC circuits and inspect ideal voltmeter and ammeter readings.
  • Prepare schematic figures for lab manuals, worksheets, quizzes, and presentations.
  • Let students practice circuit representation using standard symbols.
  • Sketch simple DC, AC, measurement, diode, LED, and transistor circuits during class discussions.
  • Build diagrams for laboratory reports and documentation.
  • Export schematic drawings as PNG or SVG images for use in other documents.
  • Save reusable circuit layouts as JSON project files.

Target Users

  • Physics students learning electricity, circuits, and measurement setups.
  • Electronics students practicing schematic representation.
  • Physics teachers and laboratory instructors preparing instructional diagrams.
  • STEM learners who need a lightweight circuit drawing tool in the browser.
  • Researchers, laboratory staff, and hobbyists who need quick schematic sketches.
  • Schools or shared-computer environments where installing desktop schematic software is inconvenient.

Core Workflow

  1. Drag components from the left component library onto the grid canvas.
  2. Use Select mode to move, rotate, rename, or edit component values.
  3. Use Wire mode to connect component terminals.
  4. For a supported DC circuit, select Simulate and review the meter readings in the Measurements panel.
  5. If simulation reports an error, check component support, values, source polarity, and wire connectivity.
  6. Use zoom and pan controls to arrange larger diagrams.
  7. Save the project as a JSON file if the layout needs to be reused later.
  8. Export the completed schematic as PNG or SVG for reports and instructional materials.

Key Features

  • Component library: resistor, capacitor, polarized capacitor, inductor, diode, LED, NPN transistor, PNP transistor, DC supply, AC supply, ammeter, voltmeter, ground, switch, bulb/load, and junction node.
  • Drag-and-drop canvas: components snap to a grid to keep schematic layouts aligned.
  • Select and Wire modes: select components for editing or connect terminals with routed wire segments.
  • Editable properties: update component labels, values, rotation, and review position information.
  • Linear DC solver: calculate steady-state node voltages and ideal meter readings for supported resistor-based DC networks.
  • Rotation and layout control: rotate components by 90-degree increments; connected wires update when components move or rotate.
  • Zoom and pan: inspect details or arrange larger circuits using the right-side controls and mouse wheel zoom.
  • Undo and redo: recover from recent layout changes.
  • Save and load: store projects locally as JSON files and reload them later.
  • Export options: download PNG, SVG, copy as image, or use the current PNG-based PDF fallback.

DC Circuit Solver

The solver performs linear, steady-state DC analysis using Modified Nodal Analysis. It is intended for introductory resistor networks and ideal measurement setups, not as a replacement for a general-purpose SPICE simulator.

Supported Models

  • Resistor: uses the resistance entered in the Value field.
  • DC supply: treated as an ideal voltage source. More than one DC source may be used unless their ideal voltage constraints conflict.
  • Voltmeter: treated as an ideal open circuit with infinite input resistance.
  • Ammeter: treated as an ideal zero-resistance element.
  • Capacitor and polarized capacitor: treated as open circuits under DC steady-state conditions.
  • Inductor: treated as an ideal short circuit under DC steady-state conditions.
  • Ground and junction: may be used to establish reference and connection points.

Unsupported Simulation Components

AC supplies, switches, bulbs/loads, diodes, LEDs, and transistors can be included in drawings but are not currently modeled by the DC solver. If any of these components are present, the app reports an error instead of estimating or fabricating a result.

Values and Engineering Prefixes

Enter a numeric value followed by an appropriate unit. Scientific notation and common SI prefixes are supported.

  • Resistance examples: 10 Ω, 4.7 kΩ, 2.2 MΩ.
  • Voltage examples: 5 V, 500 mV, 1.2e3 V.
  • Recognized prefixes: p, n, u or µ, m, k, M, G, and T.

Polarity, Reference, and Meter Readings

  • The long plate and plus sign identify the positive terminal of a DC supply. Rotating the component also rotates its polarity.
  • A ground symbol establishes the 0 V reference. If no ground is present, the negative terminal of the first DC supply is used as the reference.
  • Voltmeter readings are signed according to the meter's first terminal relative to its second terminal. Rotate the meter if the opposite sign convention is desired.
  • Ammeter readings are currently displayed as magnitudes.
  • Default reference designators are V1, V2, and so on for voltage sources; VM1, VM2 for voltmeters; and AM1, AM2 for ammeters.

Electrical Connectivity

Connect components by starting and ending wires on their terminal markers. Wire segments that share endpoints belong to the same electrical node. Two wires that merely cross between their endpoints are not automatically connected; use a junction node or redraw the wires so they share an endpoint when an electrical connection is intended.

Worked Example

For a single 10 Ω resistor connected across a 5 V DC supply, an ideal voltmeter placed across the resistor reads 5.000 V and an ideal series ammeter reads 0.500 A:

I = V / R = 5 V / 10 Ω = 0.500 A

Troubleshooting Simulation Errors

  • Floating node or open circuit: check that each required terminal is connected to the intended network.
  • Conflicting ideal sources: inspect source values and polarities, especially sources connected in parallel.
  • Invalid value: enter a numeric resistance or voltage using a supported engineering prefix.
  • Unsupported component: remove that component from the simulated network or use the schematic as a drawing only.
  • Unexpected sign or voltage: check source polarity, meter orientation, and the selected reference node.

Strengths

  • Runs in the browser with no installation requirement.
  • Provides a focused circuit drawing workflow for education and quick documentation.
  • Uses a grid-based canvas for clean alignment.
  • Includes common passive components, sources, meters, switches, loads, junctions, diodes, LEDs, and transistors.
  • Supports editable labels and values for classroom and report-ready diagrams.
  • Saves projects locally as reusable JSON files.

Current Limitations

The app includes a basic steady-state linear DC solver. It is not a general-purpose SPICE simulator.

  • Electrical nets are derived from wire endpoints. Mid-segment crossings do not automatically create junctions.
  • The PDF export currently falls back to PNG export rather than generating a true PDF file.
  • DC simulation currently supports resistors, DC supplies, ideal ammeters and voltmeters, grounds, junctions, capacitors as open circuits, and inductors as ideal shorts. Nonlinear and stateful components are not yet supported.
  • Component symbols are fixed to the included library unless the HTML source is extended.

Recommended Classroom Applications

  • Ohm's law circuit diagrams with resistor, DC supply, ammeter, and voltmeter.
  • Series and parallel resistor circuit activities.
  • Kirchhoff's voltage and current law worksheets.
  • RC, RL, and RLC introductory schematic examples; simulation is limited to their DC steady-state ideal models.
  • Diode and LED polarity lessons using drawing mode; nonlinear simulation is not yet supported.
  • Transistor switching and amplification concept diagrams using drawing mode; transistor simulation is not yet supported.
  • Instrument connection diagrams for laboratory procedures.
